Indexer解析

Indexer 是 Informers 机制中缓存层的核心索引引擎，它通过多级索引实现高效的对象检索。

Indexer 在数据流中的关键作用：

  1. 持久化存储：作为本地缓存存储从 API Server 获取的资源对象
  2. 索引加速：提供基于自定义索引的快速检索能力
  3. 事件分发基础：为事件处理器提供查询上下文

5.设计特点总结

  1. 三级索引结构
    索引名 → 索引值 → 对象键集合

  2. 存储优化原则

    • 对象实体只存一份在 items
    • 索引仅存储键名（而非对象指针）
    • 空集合自动回收（内存优化）

  3. 数据去重存储
    核心对象仅存储在 items 中，索引仅存储键

  4. 惰性计算
    索引值在添加/删除时实时计算

  5. 并发安全
    通过细粒度读写锁 (sync.RWMutex) 保证一致性
